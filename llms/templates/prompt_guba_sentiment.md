# 个股散户情绪分析（股吧文本）

## 你的任务

下面是某只 A 股在东方财富「股吧」里最近 24 小时的发帖标题列表。请判断**散户群体当前的整体情绪倾向**，输出结构化 JSON。

## 输入格式

每行一条帖子：

```
[发布时间|点击数|评论数|置顶] 标题
```

- `置顶` 为 `T` 表示该帖被吧主置顶，通常是几天前的老帖或公告，**不代表当期散户情绪**，请忽略或显著降权。
- 点击/评论数反映关注度，可作为权重参考，但**不要**因为是热帖就默认它代表多数人。

## 判断要点（必须遵守）

### 1. 区分「散户自发发言」与「资讯转贴」

股吧里混有大量：
- 资讯号发的新闻（作者名常含「资讯」「财经」「证券」，标题像新闻稿）；
- 散户转发的研报、公告、财经文章；
- 纯数据贴、纯提问贴（「什么时候分红」「这个价位能买吗」）。

**这些不反映情绪**。同一个资讯会被几十个人转发，若当情绪计入会严重失真。
请先在心里剔除这类内容，只对**真正表达了看多看空立场**的帖子计票。

### 2. 识别散户黑话与反讽

| 表达 | 含义 |
|---|---|
| 梭哈 / 满仓干 / 上车 / 抄底 / 加仓 | 看多 |
| 割肉 / 下车 / 清仓 / 跑路 / 套牢 / 退市 | 看空 |
| 护盘 / 庄家 / 托 / 洗盘 | 通常带怀疑或抱怨，偏负面 |
| YYDS / 真香 / 稳了 / 起飞 | 看多 |
| 「这票废了」「没救了」「又一波韭菜」 | 看空 |
| 反讽（「明天涨停」「感谢庄家」） | 需按语境判为负面，不要照字面理解 |
| 纯提问、纯讨论基本面、无立场 | 中性 |

### 3. 输出三分类占比，不要输出总分

你**只**需要给出 `bullish_ratio` / `neutral_ratio` / `bearish_ratio` 三个占比（合计必须等于 100）。
总分由程序按固定公式计算，你不需要给。

### 4. 置信度必须按样本量封顶（硬规则）

先数出「有效散户自发帖」的条数（记作 N，填到 `effective_count`），再按下表取 `confidence` 上限：

| 有效自发帖数 N | confidence 上限 |
|---|---|
| N = 0 | 0（并令三个占比都为 33） |
| 1 ≤ N ≤ 4 | 20 |
| 5 ≤ N ≤ 14 | 40 |
| 15 ≤ N ≤ 29 | 60 |
| 30 ≤ N ≤ 59 | 80 |
| N ≥ 60 | 95 |

**这是上限，不是目标值**。若帖子立场高度分散、大量是梗/水帖、或明显有人在刷屏，还要在此基础上继续下调。
宁可给低置信度，也不要给一个看起来精确但站不住的结论 —— 低置信度会被前端降级展示，高置信度的错误结论会直接误导交易。

### 5. 不要用你自己的股价知识

只依据帖子内容判断。你不知道这只股票当前的股价、基本面、近期走势，**不要**引入外部信息推测情绪。

## 帖子列表

$posts

## 输出格式（严格 JSON，不要任何解释、不要 ```json 围栏）

```json
{
  "bullish_ratio": 整数 0-100,
  "neutral_ratio": 整数 0-100,
  "bearish_ratio": 整数 0-100,
  "effective_count": 整数，有效散户自发帖条数,
  "confidence": 整数 0-100，遵守上面的封顶规则,
  "heat_level": "冷清|正常|活跃|过热",
  "dominant_topic": "一句话（不超过 40 字），散户当前最集中在讨论什么",
  "reasoning": "60-150 字，说明判断依据。必须引用帖子里出现的具体说法或黑话作为证据，不要空泛",
  "keywords": ["3-6 个高频词"],
  "notable_posts": [
    {"title": "帖子标题原文", "stance": "看多|看空|中性"}
  ]
}
```

补充要求：

- `notable_posts` 给 3-5 条**最能代表分歧**的帖子（不要全挑同一立场）。
- 三个占比之和必须严格等于 100；若无法整除，请调整中性占比使其凑满。
- 所有字段必须存在，不可省略。
